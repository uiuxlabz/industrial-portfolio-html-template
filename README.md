# INDUSTRO — Industrial Portfolio & Engineering HTML Template

**Precision Engineering, Global Reach.**

## Design System

### Colors
- **Charcoal** `#1F2937` — Primary dark background
- **Cyan** `#0891B2` — Accent, CTAs, highlights
- **Cyan Light** `#22D3EE` — Hover states, gradients
- **Dark** `#111827` — Page background, deep sections
- **White** `#FFFFFF` — Headings, text on dark

### Typography
- **Sora** — Headings (weights: 300-800)
- **Inter** — Body text (weights: 300-600)

### Features
- CSS custom properties for full theme control
- Fluid typography with `clamp()`
- Smooth scroll-driven reveal animations
- `prefers-reduced-motion` support
- Mobile-first responsive design (980px / 720px breakpoints)
- Semantic HTML with ARIA attributes
- No frameworks — pure HTML, CSS, vanilla JS

## Customization

### Colors
Edit the CSS custom properties in `assets/css/style.css`:

```css
:root {
  --clr-cyan: #0891B2;       /* Change accent color */
  --clr-charcoal: #1F2937;   /* Change dark surfaces */
  --clr-dark: #111827;       /* Change page background */
}
```

### Typography
Swap Google Fonts by updating the `@import` URL and the `--ff-heading` / `--ff-body` variables.

### Content
All text content is inline in the HTML files — edit directly. Images are in `assets/img/` and can be replaced with your own.
